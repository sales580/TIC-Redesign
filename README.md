# Toronto Islamic Centre: website redesign concept

A design concept for the Toronto Islamic Centre website. It is **not** the centre's official website.

- The website is `index.html` plus its pictures (the `.webp`, `.jpg` and `.svg` files with a short code in their name).
- `TIC-weekly-class-planner.pdf` and `TIC-weekly-class-schedule-for-phones.pdf` are the downloads on the Classes page.
- `TIC-class-posters-all.pdf` holds the class flyers.

Pictures are sample photos or screen captures standing in for the centre's own pictures, and the centre has not yet approved the content.
